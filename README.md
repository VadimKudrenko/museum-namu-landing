# 🎨 NAMU Museum

**NAMU Museum Landing Page** – a responsive and visually appealing one-page website designed to represent an art museum. The purpose of the project is to showcase current exhibitions, promote the gallery, and allow users to subscribe to updates through a clean and user-friendly interface.

## 🔗 Live Preview  
Expirience the live website: [view the live demo here](https://vadimkudrenko.github.io/museum-namu-landing/)

## 🛠️ Technologies Used  
### Core
- **HTML5** – Markup language  
- **SCSS** – Styling and nesting support  
- **JavaScript (ES6+)** – Interactive behavior  

### UI/UX
- **Swiper (v10.0.4)** – Image galleries  

### Development & Deployment
- **ESLint** – Code quality and linting  

## ✨ Features  
- **Responsive Design**: Fully optimized for Desktop (1440px / 1280px), Tablet (640px), and Mobile (>320px), with no horizontal scrolling issues.
- **SEO basics**: Compliance with the rules of semantic layout and attention to SEO optimization.
- **Sticky Header**: The header stays fixed at the top while scrolling, improving navigation and usability.  
- **Adaptive Logo**: The logo changes its positioning when scrolling to enhance visual appeal and match the dynamic layout.  
- **Mobile-Optimized Images**: Images adapt to different screen sizes and are delivered in lighter formats for tablets and mobile devices to improve loading speed.  
- **Hamburger Menu**: Implemented for better navigation on mobile devices.  
- **Interactive Animations**: Unified hover and scroll-based animations across elements (buttons, blocks, images).  

## 🚀 Getting Started

Follow these instructions to run the project locally:

### 1. Clone the repository
```bash
git clone https://github.com/VadimKudrenko/museum-namu-landing.git

cd museum-namu-landing

# Using VSCode with Live Server:
code .
# Then click "Go Live"

# Or open manually:
open index.html
# (or double-click the file in your file explorer)
```

### 2.Install dependencies:
```bash
npm install
# or
yarn install
```

### 3.Run the project locally:
```bash
npm start
# or
yarn start
```
